# Contributing

Terima kasih sudah membantu project ini.

## Alur

1. Buat branch dari `main`.
2. Tambah perubahan kecil dan test bila perlu.
3. Buka pull request dan jelaskan perubahan.
4. Minta review sebelum merge.

## Gaya kode

- JavaScript dengan indentasi 2 spasi.
- Fungsi kecil dan nama yang jelas.
- Jalankan `node --test` sebelum membuka pull request.
